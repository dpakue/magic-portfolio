## Overview

Help 2 Help, inc is building hospitals in Africa to expand access to healthcare. Telling their story was a great honor. From consultation to design and development, this was as much a passion project for me as it was for them!

## Key Features

- **Modern Responsive Design**: Modernized a Classic WordPress Block Theme with Elementor plugin and custom CSS.
- **Integrated Donation Processor**: Researched, secured, and integrated a zero transaction fee donation processor for tax exempt organizations.


## Technologies Used

- **WordPress**: Classic Block Theme. Elementor plugin.
- **Front-End Technologies**: JavaScript, CSS, HTML.
- **All-in-One SEO (AIOSEO)**: Benchmarking and validation of SEO performance retention.
- **Content Delivery Network**: For faster media asset load times.
- **Photoshop**: Media editing and production.

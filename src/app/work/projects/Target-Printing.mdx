## Overview

Independantly designed, developed and launched a commercial printing website with a state-of-the-art custom design studio in under 6 months, learning how to persevere under difficult work conditions.

## Key Features

- **Custom WordPress Theme**: Built a custom WordPress theme with reusable UI elements focusing on accessibility and responsiveness.
- **Custom WP Backend and Frontend UI**: Developed custom WP backend UI for Lumise plugin store management and customized front end product designer UI for brand consistency throughout Javascript and CSS in plugin theme files.
- **Dynamic Pricing**: Handled product development for initial 5 SKUs including competative analysis of pricing teirs that was used to incorporate bulk pricing discounts that I programed to appear dynamicly as customers increased product quantities.


## Technologies Used

- **WordPress**: Custom Developed Theme
- **Front-End Technologies**: JavaScript, CSS, HTML
- **Plug-ins**: Lumise Product Designer
- **File Management**: cPanel

## Challenges and Learnings

A key challenge with this project was product development. The main SKUs required price variations for size, color, quantity and design placement. This required a lot of research and development to ensure that every combination was competative and profitable.

## Outcome

I was able to deliver a modern custom print site on time and underbudget that was stable and up to par with industry leaders such as Uberprints and Custom Ink. This startup was part of a venture studio that has since shifted its focus towards other projects and uses the print shop only to service its other inhouse brands. ⚠️ NOTE: They no longer maintain the Lumise Design Studio and products I developed.
